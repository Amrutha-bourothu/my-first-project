## Digital Clock using Python

This is a simple digital clock project created using Python.  
It displays the current time in hours, minutes, and seconds format.

#  Features
- Shows real-time current time
- Updates every second automatically
- Simple and easy Python code

#  Technologies Used
- Python
- Time module

#  How to Run
1. Open the file in any Python editor (like VS Code)
2. Run the file:
   python digital_clock.py
3. The current time will display and update every second

#  Output Example
10:25:01  
10:25:02  
10:25:03  

#  Project File
- digital_clock.py
